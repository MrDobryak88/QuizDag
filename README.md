# QuizApp - Программа проверки знаний

Десктопное приложение на Python для создания и прохождения тестов. Поддерживает множественные темы, два типа вопросов, визуализацию результатов и двуязычный интерфейс.

> ℹ️ **Статус**: Учебный проект, демонстрирующий навыки работы с GUI, файлами и визуализацией данных на Python.

---

## 📋 О проекте

Приложение позволяет:
- Создавать тесты по различным темам
- Добавлять вопросы двух типов: множественный выбор и краткий ответ
- Проходить тесты с подсчётом результатов
- Просматривать историю прохождений с графиками
- Экспортировать результаты в CSV
- Переключать язык интерфейса (русский / английский) и тему оформления

**Цель проекта**: отработать навыки разработки десктопных приложений, работы с файловой системой, обработки данных и создания интуитивного интерфейса.

## 📦 Установка и запуск

### Требования
- Python 3.8 или выше
- Установленные зависимости (см. `requirements.txt`)

### Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone <ссылка-на-репозиторий>
cd QuizApp

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите приложение
python myproject.py
```

### Файлы данных
При первом запуске автоматически создаются:
- `questions.json` — база вопросов и тем
- `results.json` — история прохождений тестов

> 💡 Файлы хранятся в той же папке, что и скрипт. Их можно редактировать вручную (осторожно) или через интерфейс приложения.

## ✨ Функционал

### Для пользователя
- 👤 Вход по имени (простая авторизация)
- 📚 Выбор темы теста или "Все темы"
- ❓ Вопросы двух типов:
  - Множественный выбор (радиокнопки)
  - Краткий ответ (текстовое поле)
- 📊 Мгновенная проверка ответов
- 📈 Итоговый результат в процентах
- 📜 История прохождений с визуализацией (график Matplotlib)
- 📤 Экспорт истории в CSV

### Для администратора / создателя тестов
- ➕ Добавление новых тем тестов
- ✍️ Добавление вопросов с выбором типа
- 💾 Сохранение изменений в JSON

### Интерфейс
- 🌓 Переключение светлой / тёмной темы
- 🌐 Переключение языка: русский / английский
- ♿ Адаптивная вёрстка на ttk-виджетах

### Архитектура кода
Приложение построено на основе одного класса `QuizApp`, который инкапсулирует:
- Загрузку/сохранение данных (`load_questions`, `save_results`)
- Управление интерфейсом (`create_main_frame`, `show_question`)
- Логику тестирования (`check_multiple_choice`, `show_results`)
- Локализацию (`get_text`, словарь `translations`)
- Настройки темы и языка (`toggle_theme`, `toggle_language`)

> 🔧 **Потенциал для рефакторинга**: при масштабировании проекта логику можно вынести в отдельные модули: `data_manager.py`, `ui.py`, `quiz_logic.py`.
